Who We Are & What We Do

Meet the Cloud Ninjas, a team of five students exploring the fundamentals of cloud computing, virtualisation, and modern deployment practices.

Our Mission

Why we built this project and what we hope to achieve.

The Cloud Ninjas set out to understand the end-to-end lifecycle of a cloud-hosted application from writing code on a local machine, committing it to a version-control system, all the way to serving it to users anywhere in the world through a Content Delivery Network.

By building and deploying this site with GitHub Pages we are putting theory into practice: we have experienced first-hand how static assets can be hosted for free, scaled automatically, and delivered with low latency to users across the globe.

What Is Virtualisation?

A core concept behind cloud computing.

Virtual Machines

A VM emulates a complete computer system in software, allowing multiple isolated operating systems to share the same physical hardware.

Containers

Containers package an application and its dependencies together, enabling consistent execution across different environments lightweight and fast.

Cloud Providers

AWS, Azure, and GCP use virtualisation at massive scale to offer Infrastructure-as-a-Service, letting anyone rent compute on demand.
